## 三、核心结论

### 3.1 对齐精度

| 方向 | 精度 | 依据 |
|---|---|---|
| **竖直** | **RMS 4.2 mm（0.2%）**，平均 +0.5，最大 10.4 | 12 个位姿实测法兰高度 |
| **水平位移** | **±6 mm（2%）** | 由高度数据允许的关节增益误差 ±2% 推出 |
| **水平绝对位置** | **未验证**，可能偏 ±15~30 mm | a1 的方向没测（见 6.1）|

正解与控制器正解对比 5 个位姿，**最大偏差 0.043 mm**（控制器只报 0.1 mm，已达量化极限）。

### 3.2 六段长度的最终值

| 参数 | 含义 | **真值（mm）** | 控制器预置 | 偏差 |
|---|---|---|---|---|
| d1 | 安装面 → J2 轴 | **431** | 377 | +14.3% |
| a1 | J1 → J2 水平偏置 | **170** | 216 | −21.3% |
| a2 | J2 → J3 | **790** | 900 | −12.2% |
| a3 | J3 → J4 | **156** | 130 | +20.0% |
| **d4** | **J4 → J5（小臂）** | **750** | 934 | −19.7% |
| d6 | J5 → 法兰面 | **132.5** | 154 | −14.0% |
| — | 垫高件 | **336.5** | — | — |

> **校验方法**：打开 URDF，`joint5` 的 origin 应该是 `xyz="0 0 0.75"`。
> 看到 `d4 = 650`、`a2 = 805`、`d4 = 828` 的文件，一律是旧版。

**控制器预置参数偏差从 −21% 到 +20%，方向不一致**——没法用单一比例修正，说明那不是按这台机器写的。

### 3.3 零位姿态

q 全 0 时：法兰中心在 `(920, 0, 1244.5)`（臂座坐标），离地 **1581 mm**，法兰面水平朝下。

## 四、做过什么

### 4.1 从零重建模型

没有图纸，唯一的尺寸来源是产品彩页 `CR20-1800彩页(3).pdf`（矢量图，无文字层，数字要人工读）。
用两组独立证据定长度：12 个位姿的高度联合标定 + 恒姿态纯平移复核。

**如果照彩页直接建模**，12 个位姿的高度误差是 **RMS 25.8 mm、最大 74.7 mm**；
按现场标定值是 **4.2 mm**。差 6 倍。

### 4.2 十二位姿标定

12 个姿态，卷尺量法兰面上下沿取平均。结果平均 +0.5 mm、RMS 4.2 mm、最大 10.4 mm。

### 4.3 逆解重建

原实现是固定阻尼 DLS + 单起点，实测**成功率只有 50%，而且失败时静默返回差 1.5 m 的解**。

重写为 **LM（阻尼自适应）+ 多起点 + 残差校验**：

| 指标 | 改造前 | 改造后 |
|---|---|---|
| 往返成功率（1 起点）| 50% | 53% |
| 往返成功率（4 起点）| — | **100%** |
| 热启动（沿轨迹逐点）| — | **2 ms/点** |

### 4.4 MuJoCo 仿真

把 URDF 转成 MJCF（`make_mjcf.py`），加材质、地面、灯光、墙。
提供五个工具：转视角看、离屏出图、物理拖动、**逆解逐帧演示**、滑块控制面板。

> ⚠️ **转换时的坑**：URDF 的 `rpy` 和 MuJoCo 的 `euler` 旋转顺序不同，
> 用 `euler=` 会让法兰朝向整体偏 90°。**必须用 `quat=`**。

### 4.5 误差定位

| 现象 | 结论 |
|---|---|
| 竖直方向很准（4.2 mm）| ✅ |
| 水平方向一直差十几毫米 | 测量侧：铅垂挂点偏心（法兰半径 58 mm），量到的是 `R ± δ` |
| 换恒姿态纯平移后 | 挂点偏心自动抵消，300 mm 命令实测 290 / 320，**误差恒定绝对值、符号不一** → 不是尺度问题 |
| 底座倾斜 | **与测距无关**——刚性旋转保距，不改变任意两点距离 |

## 五、遇到的问题

### 5.1 厂家资料

| 问题 | 后果 |
|---|---|
| 六段长度设计值表未提供 | 唯一来源是彩页，数字要人工读图 |
| 关节限位表未提供 | 控制器 J1~J5 统一填 ±130°，与真实行程未必一致 |
| 零位定义未提供 | 六个轴只能现场手动标定，且**标定结果无接口可读**，无法备份 |
| 法兰接口图未提供 | 末端执行器接口需现场实测后设计 |
| 质量/惯量参数未提供 | 动力学仿真与前馈控制做不了 |
| DH 参数表未提供 | 控制器里预置的那套是错的（见 3.2）|

### 5.2 控制器与 SDK（均已在现场解决）

| 问题 | 处理 |
|---|---|
| **SDK 版本不匹配** | 机器上有两份 SDK 动态库。用错版本时 TCP 连接**成功**、`get_connection_status` 返回 SUCCESS，但**所有指令返回 −1**，示教器报「指令 0x20c6,0x7181,0x7183,0x3211 不存在」。确认用环境自带那份（`_nrc_host.so` 4574384 字节）|
| 少量 SDK 函数不可用 | `get_current_mode`、`get_speed`、`get_robot_running_state`、`get_robot_switch`、`queue_motion_get_queuelen`、`get_pos_reachable` 因参数按值传递无法返回正确值；改用关节角与伺服状态绕开 |
| 控制器预置 DH 错误 | 在示教器上按 3.2 的真值逐项改正，改完正解与模型一致到 0.043 mm |

### 5.3 装配

垫高件实际不水平（左右方向约 0.45°）。它把整机在世界坐标里转了一个角度——法兰绝对位置横移 12~14 mm——
**但不改变任意两点距离，所以不影响测距结论**。已整改。

它的真实影响在**贴墙作业**：模型里的「竖直」相对实际竖直偏 0.45°，打印 2 m 高的竖线顶端会偏约 16 mm。
这个需要在装墙前标定，属安装标定，不是模型参数。

## 八、踩坑清单

这些都是实际花时间踩过的，记下来避免重复。

### 8.1 SDK 相关

1. **不要手动设 `PYTHONPATH` 指向 `nrc_sdk/`** ——会盖掉环境里正确版本的 SDK，导致所有指令返回 −1。
2. **`Connect break` 是断开连接时打印的**，不是连接失败，别看反。
3. **连不上第一件事看急停**，不要先怀疑网络或代码。急停后连接直接断开，SDK 不给明确原因。

### 8.2 测量相关

4. **铅垂法测半径不可用**：法兰盘面朝下看不见中心，绳的挂点每次都不一样，量到的是 `R ± 挂点偏心`（偏差约等于法兰半径 58 mm）。
5. **要抵消挂点偏心，两端姿态必须完全相同**——先解 IK 再 `moveJ`，或用 `moveL`。用折 q2 的方式「后移」会让法兰转动，偏心就不抵消了。
6. **卷尺量高度可靠（±5 mm），铅垂投影到地面不可靠（±15 mm）**。
7. **量尺必须同时记录当时的关节角**——没有位姿的尺子读数，事后只能当上限看。

### 8.3 MuJoCo / 代码相关

8. **URDF → MJCF 必须用 `quat=`**，`euler=` 旋转顺序不同，会让法兰朝向偏 90°。
9. **MuJoCo 会丢弃 fixed joint**，`riser`、`tcp` 这些 body 要特殊处理。
10. **改 URDF 后必须重跑 `make_mjcf.py`**，`nbt_arm6.xml` 是生成的产物。
11. **清理 run 时注意别删掉图片**——图片所在的 run 没有文字，按「空 run」删会连带删掉图。

### 8.4 逆解相关

12. **单起点 IK 会静默失败**：50% 的成功率，失败时返回一个差 1.5 m 的解而不报错。
   做可达性判断必须用 `ik_ex()` 看返回的 `ok`，或者至少检查残差。
13. **多起点测试必须让随机流推进**：如果每次调用都 `default_rng(0)`，
    测的其实是同一组起点，成功率会被高估。
14. **Jacobian 的符号要和步进公式配对**：几何 Jacobian 是 `dp/dq`，误差是 `e = 目标 − 当前`，
    所以 `de/dq = −J`，用几何 Jacobian 时必须写 `+J⁺e`。搞反了会全部发散。

## 九、一句话总结

**竖直方向已验证到 4.2 mm（0.2%），水平位移 ±6 mm（2%），绝对横向位置因 a1 方向未测仍有 ±15~30 mm 不确定度。**

**最大的障碍不是算法，是资料**——没有图纸、控制器参数全错，模型是从彩页 + 现场标定反推出来的。
