## 一、先说清楚：这里的"仿真"是什么

**不是动力学仿真，是「几何运动学 + MuJoCo 三维呈现」。**

很多人找"仿真代码"时以为会有一个带电机、带控制器、带接触力的物理模型。这里**没有**。实际的构成是两块：

| 块 | 干什么 | 用什么 | 在哪 |
|---|---|---|---|
| **运动学** | 正解、逆解、雅可比、碰撞距离 | **纯 numpy**，不依赖 MuJoCo | `arm_env.py` |
| **三维呈现** | 把关节角画成 3D 画面 | **MuJoCo 4.0.0** | `02_mujoco仿真/` |

所以：

- 想算"这个关节角末端在哪" → 用 `arm_env.py`，跟 MuJoCo 无关
- 想看"这个姿态长什么样" → 用 MuJoCo
- 两者之间唯一的接口是 **关节角 q(6 个数)**，不是物理量

唯一的例外是 `mujoco_play.py`，它开了 MuJoCo 的重力和阻尼，可以拿鼠标拖着机械臂玩，但**没有做力矩控制**。

## 四、MuJoCo 部分：五个脚本，各管一件事

全部在 `02_mujoco仿真/`，**都在 Windows 上跑**（Python 3.12 + mujoco 4.0.0）。

### 1. `mujoco_view.py` —— 转着看

最基础的查看器。加载 MJCF，设一个关节角，用鼠标转视角。

```bash
python mujoco_view.py                     # 停在零位
python mujoco_view.py --q 0,0,0,0,90,0    # 指定位姿（度）
python mujoco_view.py --sweep 4 --amp 60  # 让 J4 来回摆，看关节怎么动
```

鼠标：左键拖=转视角，右键拖=平移，滚轮=缩放。

### 2. `mujoco_ik.py` —— 逆解演示（最直观的一个）

窗口里自动沿墙面走蛇形，每到一个目标点就用 `arm_env` 跑逆解，**把迭代过程逐帧播放出来**。

```bash
python mujoco_ik.py                  # 默认速度
python mujoco_ik.py --speed 0.03     # 迭代放得更快
python mujoco_ik.py --hold 1.0       # 每个点停久一点
```

画面里：**红球=当前目标**，**橙点=法兰走过的轨迹**，**灰点=整条规划路径**。

### 3. `mujoco_render.py` —— 离屏出图

不弹窗口，直接存 PNG。做报告插图用。

```bash
python mujoco_render.py --q 0,0,0,0,0,0 --out media/zero.png
python mujoco_render.py --azim 135 --elev -12 --dist 4.2
```

### 4. `mujoco_play.py` —— 能拖的物理模式

开了重力，可以用鼠标直接拖机械臂，松手后它会自己动。（实验性质，没有力矩控制。）

```bash
python mujoco_play.py --gravity      # 开重力
python mujoco_play.py --damping 2.0
```

### 5. `arm_panel.py` / `launcher.py` —— 图形界面

`arm_panel.py` 是「六个滑块 + 右侧实时 MuJoCo 画面」；
`launcher.py` 是带按钮的总入口，`start_sim.bat` 双击即可。

```bash
python arm_panel.py --wall 1.10      # 带墙面
python launcher.py                   # 按钮式总入口
```

## 五、URDF → MJCF 是怎么转的

`01_模型_URDF与MJCF/make_mjcf.py` 做的事：

1. 解析 URDF 的 link/joint 树（**MuJoCo 会丢弃 fixed joint**，所以 `riser`、`tcp` 这些要特殊处理）
2. **姿态必须用 `quat=` 不能用 `euler=`**
   > 这是踩过的坑：URDF 的 `rpy` 和 MuJoCo 的 `euler` 旋转顺序不同，
   > 用 `euler=` 会让法兰朝向整体偏 90°，而且只在某些关节角下才看得出来。
3. 给每个 link 挂材质（`cast` / `paint` / `gold` / `steel` / `rubber`）
4. 加地面棋盘格、天空盒、灯、可选的墙

```bash
python make_mjcf.py nbt_arm6.urdf --wall 1.10
```

## 六、运动学部分（`03_运动学与逆解/`）

核心是 `arm_env.py` 里的 `UrdfArm` 类：

| 方法 | 作用 |
|---|---|
| `fk(q)` | 正解，返回每个 link 的 4×4 位姿 |
| `jacobian_geo(q)` | 几何雅可比，**一次 FK 算完**（比数值差分快 7 倍）|
| `ik(q0, target)` | 位置逆解，LM + 多起点，返回 `(q, 残差)` |
| `ik_ex(...)` | 同上，额外返回**是否收敛**——做可达性判断必须用这个 |
| `ik_pose(q0, Pt, Rt)` | 位姿逆解（位置 + 姿态）|

**逆解的实测指标**（60 个随机可达位姿）：

| 起点数 | 成功率 | 中位耗时 |
|---|---|---|
| 1 | 53% | 50 ms |
| 4 | 100% | 8 ms（冷启动）|
| 8（默认）| 100% | 17 ms |

热启动（沿轨迹逐点求解）**中位 2 ms**。

验证脚本：`fk_verify.py`（正解）、`ik_verify.py`（逆解回归）、`ik_tune.py`（起点数扫描）。

## 八、模型的关键数字

```
d1=431  安装面→J2 轴        a1=170   J1→J2 水平偏置
a2=790  J2→J3              a3=156   J3→J4
d4=750  J4→J5（小臂）       d6=132.5 J5→法兰面
垫高件=336.5
```

零位：法兰在 `(920, 0, 1244.5)`（臂座坐标）/ 离地 1581 mm，法兰面水平朝下。

**对齐结果**：12 个位姿高度 平均 +0.5 mm、**RMS 4.2 mm**、最大 10.4 mm；
正解与控制器正解最大偏差 **0.043 mm**（控制器只报 0.1 mm，已达量化极限）。
