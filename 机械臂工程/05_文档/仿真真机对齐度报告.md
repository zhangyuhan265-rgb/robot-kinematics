> 2026-11-07 现场实测。12 个位姿，测法兰盘中心离地高度（竖直卷尺，上沿下沿取平均）。
> 结论：**RMS 4.1 mm，最大 10 mm** —— 模型可以直接用于规划和训练环境。

## 四、两个异常，记下来

### 1. 位姿 5 的 −10 mm

法兰在 **2.06 m** 高处，皮尺量这么高本身就费劲（±10 mm 很正常）。
但也可能是高伸展姿态下的真实偏差。**下次用激光测距或放低点位复测这一发。**

### 2. J5 正负行程不对称 —— **这是设计如此，不是零位错误**

实测：`q5 = +45°` 超限，`q5 = −90°` 正常。

现场确认的原因：**J5 只能逆时针转，顺时针方向会让内侧肘部撞到小臂。**
所以正方向本来就没有（或极少）行程，负方向自由。

**⚠️ 但这件事对模型有实际影响：**

> **URDF 里 `joint5` 的限位是 `±130°`，这是错的。**
> 真实是：**负方向约 −130°（待确认），正方向几乎没有（< 45°，具体值待确认）**。

后果：**规划时如果用到 q5 > 待定上限，仿真会认为可行、真机直接超限**。

**要在 URDF 里改掉 `joint5` 的 `<limit>`**，`upper` 改成一个小的正值。
具体数值需要从示教器上确认，或者在 +10°/+20°/+30° 位置试探出来。

## 七、水平方向：怎么验的（2026-11-07 补测）

竖直方向用 12 个位姿卡住了 5 个长度，但**水平方向一直没验**。原因是 `q1` 绕竖直轴转，法兰高度完全不变——12 个高度数据对水平方向零信息。

### 7.1 先弄清「哪个参数没被验」

零位时只有两段有水平分量：

| 段 | 符号 | 长度 | 零位方向 | 对 R 的贡献 |
|---|---|---|---|---|
| 底座→肩（J1→J2） | a1 | 170 | 水平 | **+170** |
| 大臂（J2→J3） | a2 | 790 | 竖直 | 0 |
| 肘（J3→J4） | a3 | 156 | 竖直 | 0 |
| 小臂（J4→J5） | d4 | 750 | 水平 | **+750** |
| 腕→法兰 | d6 | 132.5 | 竖直向下 | 0 |

`R = a1 + d4 = 920`。d4 被高度数据卡死（改成 698，RMS 从 4.2 崩到 15.0，位姿 5 差 44 mm）；**a1 对高度完全不可见**（改成 118，12 个残差一个数字都不变）。所以唯一没被验证的是 a1。

每个轴的零位偏置也排除了。给 1° 零位误差，`Δh/ΔR` 分别是 q2 → −0.91、q3 → −25（荒谬）、q5 → −0.009（二阶，看着能藏）。但 q5 零偏 22.5° 时 12 个高度残差 RMS 从 4.2 升到 21.0（位姿 5/6/8 各错 35~37 mm），**藏不住**。

### 7.2 铅垂法失败，原因记下来

做法：从法兰吊线坠落到地面，转 q1 打点，量弦长 `2R·sin(Δ/2)`。

**失败。** 同一对点先后量出 455 / 530（30° 跨度）和 865 / 1050（60° 跨度），反解 R 从 865 散到 1050。

原因：**法兰盘面朝下、看不见中心，绳的挂点每次都不一样。** 量到的是 `R + δ`，δ 是挂点偏心量，几十毫米且每次都变。用四点圆拟合验证：四个点各自到圆心的半径从 669 散到 773（相差 90 mm），根本不共圆。

> **这个办法在「看不见盘心」的约束下重复性只有 ±80 mm，而我们分辨的是 50 mm，不够用。以后别再走这条路。**

### 7.3 最后是怎么验成的

**① a1 直接用钢板尺量。** a1 只有 150 mm 量级，候选值 118 / 170 / 275 相差 30% 以上，一把尺子一眼就能分开。实测 **a1 = 170**，与宣传册一致，模型不改。

**② 水平尺度用「恒姿态纯平移」验。** 关键点：挂点偏心 δ 是固定在法兰坐标系里的向量，**只要两端姿态完全相同，δ 在世界里的方向就不变**，两次标记的距离严格等于法兰中心的位移，δ 完全抵消——所以**不需要挂在盘心**。

用 6 维数值 Jacobian 解 IK，约束姿态不变、只沿 X 平移：

| 点 | 法兰位置（控制器报） | 关节角 |
|---|---|---|
| P1 | (920.0, 0, 1244.5) | q = [0, 0, 0, 0, 0, 0] |
| P2 | (1220.0, 0, 1244.6) | q = [0, −23.65, +28.78, 0, +5.12, 0] |
| P3 | (620.0, 0, 1244.5) | q = [0, +21.28, −17.13, 0, +4.15, 0] |

相邻两点应有距离都是 300.0 mm（P2–P3 是 600 mm）。

实测：`P1–P2 = 290`、`P1–P3 = 320`、`P2–P3 = 610`。

**判定：水平尺度没有误差。**

- 如果是尺度问题，两条弦必须同向同比例。按 `290/300 = 0.967` 推，600 应量到 580；按 `610/600 = 1.017` 推，300 应量到 305。**没有任何单一尺度能同时解释。**
- 三条严格自洽：`290 + 320 = 610`（差 0 mm），说明三个地面点本身完全共线，问题只在标点位置。
- 反推标点偏差：P1 = 0、P2 = −10 mm、P3 = **−20 mm**。P3 是在机械臂折起来的位姿下标点的，**铅垂线很可能被小臂/腕部挡住往内带了 20 mm**。

### 7.4 操作上的两条教训

1. **铅垂要在伸展位姿下标点**。折叠位姿下绳子会蹭到臂体被带偏（本次 P3 偏了 20 mm）。
2. **想抵消挂点偏心，两端姿态必须完全相同**：先解好 IK 再 `moveJ`，或用 `moveL`。用折 q2 的方式「后移」会让法兰转动，δ 就不抵消了。
