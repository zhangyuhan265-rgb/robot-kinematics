## 〇、记号约定（先统一，否则后面必错）

| 本文写法 | 课件写法 | 读法 | 作用 |
| :--- | :--- | :--- | :--- |
| `R(A←B)` | `ᴬ_BR` | B 相对 A | **把 B 系的坐标换到 A 系** |
| `ᴬP` / `ᴮP` | 同 | 点 P 在 A 系 / B 系里的坐标 | — |

> **箭头方向是唯一要紧的事**：`R(A←B)` 的箭头指向结果所在的坐标系。
> 反过来就取转置：`R(B←A) = R(A←B)ᵀ` —— 这就是 p16–18 证的那条。

## 一、这一节在讲什么

**一句话：同一个 3×3 矩阵，有三种完全不同的解释。**

| 用法 | 数学形式 | 谁在动 |
| :--- | :--- | :--- |
| ① 描述 frame 的姿态 | `R(A←B) = [ᴬX̂_B │ ᴬŶ_B │ ᴬẐ_B]` | 都不动，只是记录 |
| ② 换坐标 Mapping | `ᴬP = R(A←B) · ᴮP` | **都不动**，换的只是尺子 |
| ③ 转向量 Operator | `ᴬP′ = R(θ) · ᴬP` | **点真的被转了** |

课件 p25 的三行总结就是这张表。

---

## 二、用法①：描述姿态

R 的第 j 列 = frame B 的第 j 根轴在 A 系里的坐标。

```text
R(A←B) 的列：  [ X_B 的方向 | Y_B 的方向 | Z_B 的方向 ]   （都在 A 系里看）
```

> 这一条已经吃透：不用背 `sin/cos`，把三根箭头转过去、并排竖写就是矩阵。

---

## 三、用法②：Mapping 换坐标（p20–21）

**前提**：两个系**只有相对转动**，原点重合。

```text
ᴬP = R(A←B) · ᴮP
```

**同一个点，没有动。** 变的只是「用哪套坐标去描述它」。

### 例题（p21）

```text
R = Rz(30°)，ᴮP = [1.732, 1, 0]ᵀ，求 ᴬP

      ⎡ 0.866  −0.5   0 ⎤ ⎡ 1.732 ⎤   ⎡ 1.000 ⎤
ᴬP =  ⎢ 0.5     0.866  0 ⎥ ⎢ 1     ⎥ = ⎢ 1.732 ⎥
      ⎣ 0       0      1 ⎦ ⎣ 0     ⎦   ⎣ 0     ⎦
```

手验两行：

```text
x = 0.866×1.732 − 0.5×1     = 1.5 − 0.5     = 1
y = 0.5×1.732   + 0.866×1   = 0.866 + 0.866 = 1.732
```

实测 `Rz(30°) @ [1.732, 1, 0] = [1. 1.732 0.]` —— 与课件一致。

## 四、用法③：Operator 转向量（p22–24）

**点真的在同一个系里被转动了。**

```text
ᴬP′ = R(θ) · ᴬP
```

### 例题（p24）

```text
ᴬP = [0, 1, 1.732]ᵀ，绕 X 轴转 30°，求 ᴬP′

      ⎡ 1   0        0      ⎤ ⎡ 0     ⎤   ⎡ 0 ⎤
ᴬP′ = ⎢ 0   0.866   −0.5    ⎥ ⎢ 1     ⎥ = ⎢ 0 ⎥
      ⎣ 0   0.5      0.866  ⎦ ⎣ 1.732 ⎦   ⎣ 2 ⎦
```

手验：

```text
y′ = 0.866×1 − 0.5×1.732 = 0.866 − 0.866 = 0
z′ = 0.5×1   + 0.866×1.732 = 0.5 + 1.5    = 2
```

实测 `Rx(30°) @ [0, 1, 1.732] = [0. 0. 2.]` —— 与课件一致。

## 五、② 和 ③ 的区别（最容易混的地方）

| | ② Mapping | ③ Operator |
| :--- | :--- | :--- |
| 谁动了 | **没人动** | **点动了** |
| 换的是什么 | 描述用的坐标系 | 点的位置 |
| 乘的矩阵 | `R(A←B)` | `R(θ)` |
| 一句话 | 「换个角度看同一个东西」 | 「把东西转过去」 |

> **⚠️ 两者数学形式完全一样（都是 R 乘一个向量）**，区别只在物理解释。
> 这正是 L2 p19/p22 要讲的「对偶性」：**把点转 +θ，等价于把 frame 转 −θ**，所以同一个矩阵能有两种读法，算出来的数字也相同。

## 六、三个基本旋转矩阵（p22–23）

```text
        ⎡ cθ  −sθ  0 ⎤        ⎡ 1   0    0   ⎤
Rz(θ) = ⎢ sθ   cθ  0 ⎥  Rx(θ)= ⎢ 0   cθ  −sθ  ⎥
        ⎣ 0    0   1 ⎦        ⎣ 0   sθ   cθ  ⎦

        ⎡ cθ   0   sθ ⎤
Ry(θ) = ⎢ 0    1   0  ⎥        ← 负号在【第 3 行第 1 列】，不在右上
        ⎣ −sθ  0   cθ ⎦
```

## 七、`Ry` 为什么跟另外两个长得不一样

**因为它也是照「列规则」写出来的，只是 x 轴的去向不同。** 三根轴的去向：

| 轴 | `Rz(θ)` 把 e₁/e₂/e₃ 送到 | `Rx(θ)` | `Ry(θ)` |
| :---: | :--- | :--- | :--- |
| e₁ (x) | (cosθ, sinθ, 0) | (1, 0, 0) | **(cosθ, 0, −sinθ)** |
| e₂ (y) | (−sinθ, cosθ, 0) | (0, cosθ, sinθ) | (0, 1, 0) |
| e₃ (z) | (0, 0, 1) | (0, −sinθ, cosθ) | **(sinθ, 0, cosθ)** |

绕 y 的正转（右手定则，拇指指 +y）把 **+z 转向 +x**，等价于把 **+x 转向 −z**。
所以第 1 列的第三个分量是 `−sinθ`，第 3 列的第一个分量是 `+sinθ`。

> **结论：不要背「Ry 的 sin 要反号」。用列规则现场推，永远不会错。**
> 快速自检：θ = 90° 时 `Ry(90°)` 应该把 x 送到 −z、z 送到 x。
> 实测 `Ry(90°) @ (1,0,0) = (0,0,−1)`、`Ry(90°) @ (0,0,1) = (1,0,0)` ✅

## 八、三条性质（p16–19，已掌握）

| # | 性质 | 含义 |
| :---: | :--- | :--- |
| 1 | 正交 | `RᵀR = R Rᵀ = I` ⇒ **`R⁻¹ = Rᵀ`** |
| 2 | det = +1 | 旋转；**det = −1 是镜像，不是旋转** |
| 3 | 列是正交单位基 | 9 个数字 − 6 个约束 = **3 DOF** |

**`RᵀR = I` 的证明只有三行**：

```text
① Rᵀ 的第 i 行 = R 的第 i 列              （转置就是行列互换）
② (RᵀR)ᵢⱼ = 第 i 列 · 第 j 列            （矩阵乘法 + ①）
③ 对角 = 1（列长 1），非对角 = 0（互相垂直） ⇒ RᵀR = I
```

**「为什么逆等于转置」分两层**：几何上点积可交换（换参考系重述）；代数上正交矩阵定义直接给。

## 九、易错点清单

| 坑 | 现象 | 怎么防 |
| :--- | :--- | :--- |
| 下标方向搞反 | 算出来的点位置镜像了 | 认箭头：`R(A←B)` 的箭头指结果所在的系；反了就是转置 |
| `Ry` 负号记错 | 绕 y 转的符号全错 | 用列规则推，θ=90° 自检 |
| 拿 `0.866` 验 `det` | 得 0.999956，以为矩阵错了 | `0.866² = 0.749956 ≠ 0.75`；要用真值 |
| 把镜像当旋转 | `det = −1` 也满足 `RᵀR = I` | 正交 ⊥ 旋转；还要 `det = +1` |
| Mapping / Operator 混 | 数字对但物理意义说反 | 问一句「谁动了？」 |
| 列长不为 1 的矩阵 | `QᵀQ ≠ I`（对角是列长的平方） | 对角元素 = 该列长度的平方 |

## 答案（做完再看）

**1.** `Rx(90°)` 三列：e₁ 不动 → (1,0,0)；e₂ 送到 z → (0,0,1)；e₃ 送到 −y → (0,−1,0)。

```text
        ⎡ 1   0   0 ⎤
Rx(90°)=⎢ 0   0  −1 ⎥
        ⎣ 0   1   0 ⎦
```

**2.** `ᴬP = Rz(90°) · [1,0,0]ᵀ = [0,1,0]ᵀ`。这是 **Mapping（换坐标）** —— 点没动，只是换成 A 系的坐标来描述。

**3.** **答案一样，都是 `(0,1,0)`。** 区别在**谁动了**：第 2 题里点是固定的、坐标系转了；第 3 题里坐标系固定、点转了。
两者给出同一个数，是因为「点转 +θ」≡「frame 转 −θ」—— 这就是 L2 要展开的对偶性。
