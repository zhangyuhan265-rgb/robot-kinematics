# Joint space vs Cartesian space（一页纸）

> 来源：林沛群《機器人學（一）》第 3 讲 p20–24、第 5 讲 p5–8
> 整理：2026-10-28　·　对应视频分P 23 / 34 / 35

---

## 0. 一句话

> **Joint space：我指定每个关节怎么转，末端划成什么样我不管；
> Cartesian space：我指定末端怎么走，每一步的关节角是算出来的。**

**你只能直接控制一头。指定了关节，末端就是算出来的；指定了末端，关节就是算出来的。**

---

## 1. 先分清三个空间（L3 p20）

```text
Actuator space        Joint space          Cartesian space
θ_motor      →→→      θ_joint     →→→      W_P（末端位姿）
           齿轮/丝杠   θ_joint=θ_motor·N   Forward Kinematics
                        ←───────────────   Inverse Kinematics
```

| 空间 | 变量 | 谁决定 |
| :--- | :--- | :--- |
| Actuator | 电机转角 | 编码器直接读 |
| Joint | 关节角 | 传动机构换算 |
| Cartesian | 末端位姿 | FK / IK |

---

## 2. 课件原文：四步，差别只在第 2、3 步的顺序

### Joint space（L5 p5）

```text
① 定义 initial / via / final points
② 【I.K.】把末端点状态 → 关节角 Θ_i
③ 在【关节空间】规划 smooth trajectories
④ 【F.K.】把关节轨迹 → 末端，检查末端轨迹可行性
```

### Cartesian space（L5 p7）

```text
① 定义 initial / via / final points        ← 和上面一字不差
② 在【末端空间】规划 smooth trajectories
③ 把规划好的每个轨迹点 → 关节角 Θ_i         （I.K.）
④ 检查 joint 状态的可行性
```

### 对照

```text
Joint space    ： 点 →【IK】→ 关节角 →【插值】→ 关节轨迹
Cartesian space： 点 →【插值】→ 末端轨迹 →【IK】→ 关节轨迹
```

**第 4 步互为镜像：在哪个空间规划，就要用另一个空间的映射去检查后果。**

| 在哪规划 | IK 次数 | 检查用什么 |
| :--- | :--- | :--- |
| Joint | N+1（只有那几个点） | F.K. 看末端划成什么样 |
| Cartesian | **采样点数**（几百~几千） | 转关节看是否超限/可行 |

课件 p7 原话：**「較高的運算負載 (i.e., IK)」**

## 3. IK 次数的真相

**via point 是你给的"关键姿态"（通常 2~5 个），采样点是规划器自动铺的。**

```text
你给的：   ●─────────●──────────●────────●      （4 个 via）
采样：     ●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●      （几千个）
                                          ↑ 每个都要 IK
```

| | IK 次数 | 2 秒 @ 1 kHz 的例子 |
| :--- | :--- | :--- |
| Joint space | via 点数 = N+1 | **4 次** |
| Cartesian space | 采样点数 = 时长/周期 | **2000 次** |

**差 500 倍。**

### 采样密度怎么定

| 依据 | 例子 |
| :--- | :--- |
| **时间**（最常见） | 每 1 ms 采一个 |
| 空间步长 | 每 0.5 mm 采一个 |
| 速度 | 高速稀、低速密 |

> 太密不是好事：IK 次数线性增长，且奇异位形附近相邻点差异太小会跳变。工业上按控制周期（1~10 ms）即可。

## 4. 判据：一句话分清

> **via point 之间的中间点，是【关节插值】出来的，还是【笛卡尔插值 + IK】得到的？**

| 做法 | 本质 |
| :--- | :--- |
| via 点用 IK 转关节角，中间关节插值 | **joint space**（哪怕端点是笛卡尔给的） |
| via 点之间在末端空间插值，每点 IK | **Cartesian space** |

---

## 5. 路径形状：在你指定的空间里才是直线

> **你在哪个空间插值，那个空间里就是直线；换到另一个空间看，一定是曲线。**

实测（2 连杆 `l1=1, l2=0.8`，末端 `(0.5,0.3)→(1.4,0.9)` 斜线）：

| | 偏离直线的距离 |
| :--- | :--- |
| Cartesian 插值 | `1e-18`（机器精度的 0） |
| Joint 插值 | 最多 **7.34 cm** |

**关节空间里各关节严格线性**（实测每步增量 `0.1451948285°`，完全相等）。

### 精确说法

```text
路径（path）  ：(θ1..θn) 在 n 维关节空间走直线     ← 一定是直的
时间律（timing）：s(t) 怎么变（匀速/三次/LSPB）      ← 可以任意
```

只要所有关节共用同一个 `s(t)`，路径就还是那条直线 —— **换时间律只改"什么时候走到哪"，不改"走哪条路"。**

## 6. 工业术语（面试用）

| 说法 | 术语 | ABB | KUKA |
| :--- | :--- | :--- | :--- |
| 点到点，到达就行 | **PTP** | `MoveJ` | `PTP` |
| 末端按轨迹走 | **CP** | `MoveL` / `MoveC` | `LIN` / `CIRC` |

| 任务 | 类型 |
| :--- | :--- |
| 搬运、上下料、码垛 | PTP |
| 喷涂、焊接、涂胶、切割 | CP |
| 装配插入 | CP（部分） |

**实际程序混着用**：空走段 PTP（快），作业段 CP（准）。

## 7. 代价对照

| | Joint space | Cartesian space |
| :--- | :--- | :--- |
| 你指定什么 | 起点/目标**关节角** | **整条末端路径** |
| IK 次数 | 1~2 次 | 采样点数 |
| 会不会失败 | 基本不会 | **可能**（不可达 / 奇异） |
| 关节限位 | 好处理 | 可能中途超限 |
| 末端路径 | 不可控 | 必须贴合 |
| 速度 | 快 | 慢（要多绕） |

**Joint space 永不失败的根因**：只要两端关节角合法，中间一定走得通（关节空间是"凸"的）。
**Cartesian 会失败的根因**：直线段中间可能超出工作空间，或穿过奇异位形。

---

## 8. 三个坑

| 坑 | 说明 |
| :--- | :--- |
| 以为 Cartesian 只算最终点 | 错，**每个采样点**都要 IK |
| 以为 via 点之间关节插值就行 | 那是 joint space，末端会走弯的 |
| 关节空间的 via 点时间戳不一致 | 6 个关节必须在**同一时刻**过 via 点，否则过不去（L5 p6） |

## 9. 实际系统怎么跑

```text
离线（规划）：算 N 次 IK，得到关节角序列 → 存下来
在线（执行）：按 1 kHz 回放关节角序列，一次 IK 都不算
```

**所以"Cartesian 贵"体现在规划阶段的计算量和内存，不是运行时的实时负担。**
这也解释了为什么 `MoveL` 执行中一般不允许改目标点 —— 整条关节序列是提前算好的。
