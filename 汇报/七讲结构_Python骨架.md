# ============================================================
# 01_剛體運動狀態描述.py
# 视频分P 02–07（57:44）｜课件 L1 p1–25（25 页）
# 一句话：把"一个物体在哪、朝哪"翻译成矩阵
# ============================================================

#%% 1-0 怎么描述刚体（p2–5）
#   · 平面：移动 2 DOF + 转动 1 DOF
#   · 空间：移动 3 DOF + 转动 3 DOF
#   · 手段：刚体上建 body frame；原点位置管移动、姿态管转动

#%% 1-1 移動（p7–8）
#   · 位置向量 P = [Px, Py, Pz]ᵀ
#   · 向量的两种用法：position vector（描述原点）/ basis vector（描述方向）

#%% 1-2 轉動：Rotation Matrix 的定义（p10–12）
#   · ᴬ_BR 的三列 = frame B 三根基向量在 A 中的坐标
#   · 每个元素是两个单位向量的点积（direct cosines）
#   · 例题：由几何图反推 R
# ★ 核心记忆：第 j 列 = 第 j 根轴转完之后指向哪

#%% 1-3 R 的三条性质（p16–19）
#   · ᴬ_BR = (ᴮ_ᴬR)ᵀ          「前后向量互换」
#   · RᵀR = I  ⇒  R⁻¹ = Rᵀ
#   · 9 个数字 − 6 个约束 = 3 DOF
#   · det = +1 旋转 / −1 镜像

#%% 1-4 三个基本旋转矩阵（p22–23）
#   · Rz(θ)、Rx(θ)、Ry(θ)  ← 用"列 = 去向"现场推，别背
#   · Ry 的负号在第 3 行第 1 列，和另两个不同

#%% 1-5 R 的三种用法（p20–25）
#   · ① 描述姿态 ② 换坐标 Mapping ③ 转向量 Operator
#   · ②③ 数学形式相同，区别在「谁动了」

## 第 2 讲 · Rotation Matrix 與轉角

```python
# ============================================================
# 02_旋转角与齐次变换.py
# 视频分P 08–16（1:29:11）｜课件 L2 p1–33（33 页）
# 一句话：把姿态拆成三个角 + 把移动和转动合成 4×4
# ============================================================

#%% 2-0 为什么要拆成三次旋转（p2）
#   · 空间转动 3 DOF，但矩阵有 9 个数
#   · 拆之前必须定：顺序 + 轴固不固定
#   · 固定轴 → Fixed angles；动轴 → Euler angles

#%% 2-1 Fixed Angles（p3–6）
#   · 由角推 R：R = Rz(α)·Ry(β)·Rx(γ)   ← 先转的写最右
#   · 例：先 X60 后 Y30 ≠ 先 Y30 后 X60
#   · 由 R 反推：β = atan2(−r31, √(r11²+r21²))，α、γ 各除 cβ
#   · 万向节锁：β = ±90° 时退化成单解

#%% 2-2 Euler Angles（p7–13）
#   · Z-Y-X / Z-Y-Z，绕动轴，先转的写最前
#   · 与 Fixed 的**对偶**：动轴 x→y→z ≡ 固定轴 z→y→x
#   · 小结：12 Euler + 12 Fixed；angle-axis、quaternion 各 3 DOF

#%% 2-3 齐次变换矩阵（p15–16）
#   · T = [[R, P], [0 0 0 1]]，把移动和转动装进一个 4×4

#%% 2-4 Mapping（p17–19）
#   · ᴬP = ᴬ_BR·ᴮP + ᴬP_Borg  → 齐次形式 ᴬP̃ = ᴬ_BT·ᴮP̃
#   · 复合：ᴬ_BT·ᴮ_CT·ᶜ_DT 连续

#%% 2-5 Operators（p20–26）
#   · 先转后移 T = [R, Q]；先移后转 T = [R, R·Q]
#   · 点动 ≡ frame 反向动
# ★ 判据：看平移列有没有被 R 乘过

#%% 2-6 变换矩阵运算（p29–33）
#   · 逆：T⁻¹ = [Rᵀ, −RᵀP]
#   · premultiply = 固定基准；postmultiply = 当前基准
```

## 第 3 讲 · 順向運動學

```python
# ============================================================
# 03_DH参数.py
# 视频分P 17–25（1:42:22）｜课件 L3 p1–39（39 页）
# 一句话：四个参数描述相邻连杆，连乘得到末端位姿
# ============================================================

#%% 3-0 运动学是什么（p2–3）
#   · 只讨论运动状态，不涉及力（那是动力学）
#   · Joint / Link 的几何关系

#%% 3-1 手臂几何：两根轴怎么描述（p4–6）
#   · 两轴的关系需要两个参数：夹角 + 公垂线距离
#   · 再加 θ_i、d_i 两个关节变量，多杆才能串

#%% 3-2 杆件上建立 Frames（p7–9）
#   · Z_i = 关节 i 的转轴
#   · X_i = 公垂线方向（a_i ≠ 0）；a_i = 0 时垂直两 Z
#   · Y_i = Z_i × X_i（右手定则）
#   · Frame {0} 与 {1} 在 θ₁=0 时重合（Craig 约定）
# ★ X 由公垂线定，Y 才用右手定则
# ⚠️ 平行时公垂线不唯一，要人为选

#%% 3-3 DH 四参数（Craig 版，p10）
#   · α_{i-1}：绕 x_{i-1}，两 Z 轴夹角（角度）
#   · a_{i-1}：沿 x_{i-1}，两 Z 轴距离（长度）
#   · θ_i：绕 z_i，两 X 轴夹角
#   · d_i：沿 z_i，两 X 轴距离
#   · 单级变换：Rx(α)·Dx(a)·Rz(θ)·Dz(d)
# ⚠️ α 是角度不是距离；平行轴时 α=0 但 a≠0

#%% 3-4 正运动学：连乘（p11–12）
#   · T₀ⁿ = T₀¹·T₁²·…，从右往左作用到点上
#   · 例题：RRR / RRRP(SCARA) / RP

#%% 3-5 三个空间（p20–24）
#   · Actuator / Joint / Cartesian
#   · θ_joint = θ_motor · N（齿轮比）

#%% 3-6 Standard DH 与对比（p27–33）
#   · 顺序相反：Rz·Dz·Dx·Rx
#   · 2 连杆平面臂：Craig 3 帧、Standard 2 帧，结果相同
# ⚠️ 两套不能混用

#%% 3-7 PUMA 560（p34–39）
#   · 6 轴 DH 表 → 连乘 → ⁰₆T 的 12+3 个表达式
```
